Git Cheat Sheet Guide

Hướng Dẫn Tra Cứu Câu Lệnh Git

Danh sách đầy đủ các câu lệnh Git thông dụng, ví dụ thực tế và giải thích chi tiết bằng tiếng Việt.

Sơ Đồ Luồng Hoạt Động Của Git (Git Workflow)
1. Working Directory
Thư mục làm việc thực tế chứa code chưa lưu trữ.
git add →
2. Staging Area
Khu vực tạm chờ đóng gói commit.
git commit →
3. Local Repository
Kho lưu trữ trên máy máy cá nhân của bạn.
git push →
4. Remote Repository
Kho lưu trữ đám mây (GitHub, GitLab...).
← git pull / fetch

1. Khởi Tạo & Thao Tác Cơ Bản Basic Workflow

git init
Cơ bản
Khởi tạo một Git Repository mới tại thư mục hiện tại. Tạo thư mục ẩn .git lưu lịch sử phiên bản.
git init
git clone
Cơ bản
Sao chép một repository từ xa (từ GitHub/GitLab...) về máy tính của bạn.
git clone <repository_url>
git status
Cơ bản
Kiểm tra trạng thái hiện tại của các file (chưa theo dõi, đã sửa đổi, đã đưa vào Staging Area).
git status
-sHiển thị dạng rút gọn (short format)
git add
Cơ bản
Thêm file đã chỉnh sửa vào Staging Area để chuẩn bị commit.
git add .
.Thêm tất cả các file thay đổi trong thư mục
<filename>Chỉ thêm một file cụ thể
git commit
Cơ bản
Lưu lại ảnh chụp (snapshot) các thay đổi từ Staging Area vào kho lưu trữ cục bộ kèm lời nhắn.
git commit -m "Nội dung commit"
--amendSửa lại ghi chú commit gần nhất hoặc bổ sung file quên add
git diff
Cơ bản
So sánh chi tiết sự thay đổi giữa Working Directory và Staging Area (hoặc giữa các commit).
git diff
--stagedXem khác biệt giữa Staging Area và commit gần nhất

2. Quản Lý Nhánh (Branch & Merge) Branching

git branch
Nhánh
Xem danh sách các nhánh hiện có hoặc tạo/xóa nhánh.
git branch
-aXem tất cả các nhánh (bao gồm cả nhánh remote)
-d <name>Xóa nhánh đã gộp (safe delete)
-D <name>Xóa ép buộc (force delete)
git checkout / git switch
Nhánh
Chuyển sang nhánh khác hoặc tạo mới và chuyển ngay sang nhánh vừa tạo.
git checkout -b <ten_nhanh>
git checkout <name>Chuyển sang nhánh có sẵn
git switch -c <name>Cú pháp mới gọn hơn của git checkout -b
git merge
Nhánh
Hợp nhất (gộp) những thay đổi từ nhánh khác vào nhánh hiện tại bạn đang làm việc.
git merge <ten_nhanh_can_gop>
git log
Nhánh
Xem lịch sử các commit đã thực hiện trên nhánh hiện tại.
git log --oneline --graph --all
--onelineHiển thị mỗi commit trên 1 dòng ngắn gọn
--graphVẽ nhánh dạng đồ họa chữ đơn giản

3. Làm Việc Với Remote (GitHub / GitLab) Remote & Sync

git remote add
Remote
Liên kết kho lưu trữ trên máy của bạn với một kho từ xa (vd: repository trên GitHub).
git remote add origin <url>
git remote -vKiểm tra đường dẫn URL remote đã liên kết
git push
Remote
Đẩy các commit từ máy cá nhân (Local Repo) lên server từ xa (Remote Repo như GitHub).
git push -u origin main
-uGhi nhớ nhánh mặc định (lần sau chỉ cần nhập git push)
--force (-f)Đẩy ghi đè ép buộc (cần cẩn trọng!)
git pull
Remote
Tải về và gộp (fetch + merge) những thay đổi mới nhất từ kho từ xa về máy local.
git pull origin main
--rebaseTải về và đặt commit mới của bạn đè lên lịch sử server
git fetch
Remote
Tải dữ liệu mới nhất từ remote về nhưng CHƯA gộp vào code của bạn (an toàn hơn pull).
git fetch origin

4. Hoàn Tác & Khôi Phục (Undo & Restore) Undo

git restore
Hoàn tác
Hủy bỏ các thay đổi chưa commit trong file hoặc đưa file ra khỏi Staging Area.
git restore <filename>
--stagedBỏ file ra khỏi Staging (tương đương git unstage)
git reset
Hoàn tác
Dịch chuyển con trỏ HEAD về commit cũ hơn. Thao tác có thể ảnh hưởng đến lịch sử.
git reset --soft HEAD~1
--softHủy commit nhưng giữ lại code trong Staging
--hardHủy commit VÀ XÓA HẲN toàn bộ thay đổi code (Cẩn thận!)
git revert
Hoàn tác
Tạo một commit mới đảo ngược kết quả của một commit cũ (Cách hoàn tác an toàn nhất khi đã push).
git revert <commit_hash>

5. Nâng Cao (Stash, Rebase & Tools) Advanced

git stash
Nâng cao
Cất tạm những công việc đang dở dang (chưa commit) vào bộ nhớ đệm để làm việc khác khẩn cấp.
git stash
git stash popLấy lại công việc cất tạm gần nhất và xóa khỏi stash
git stash listXem danh sách các lần stash
git rebase
Nâng cao
Chuyển toàn bộ nhánh hiện tại sang điểm bắt đầu từ đỉnh nhánh khác, giúp lịch sử commit thẳng đẹp.
git rebase main
git cherry-pick
Nâng cao
Chọn và áp dụng đúng 1 commit cụ thể từ nhánh khác về nhánh hiện tại.
git cherry-pick <commit_hash>
git config
Nâng cao
Thiết lập cấu hình thông tin cá nhân (Tên, Email) khi làm việc với Git.
git config --global user.name "Tên Của Bạn"
user.emailCấu hình Email: git config --global user.email "email@example.com"

Không tìm thấy câu lệnh phù hợp!

Thử tìm từ khóa khác như "commit", "push", "checkout" hoặc "branch".

Đã sao chép câu lệnh vào bộ nhớ tạm!
