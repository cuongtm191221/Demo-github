Các bước đẩy tài nguyên lên git:
1: git init
2: git add .
3: git commit -m "nội dung commit"
4: git remote add origin "đường dẫn tới repo trên github"
5: git push -u origin main

Các câu lệnh git:
git init (khởi tạo)
git add . (add những phần cần đẩy lên git)
git commit -m "nội dung commit" (commit)
git remote add origin "đường dẫn tới repo trên github"  (liên kết với repo trên github)
git push -u origin main (push)
git branch (xem danh sách các nhánh)
git checkout -b "branch_name" (tạo nhánh mới)
git checkout main (chuyển về nhánh main)
